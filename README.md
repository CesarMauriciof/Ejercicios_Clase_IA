# Ejercicios Clase IA

## Descripción

Repositorio que alberga todos los ejercicios de la materia de **Inteligencia Artificial**. En este proyecto se implementan y experimentan conceptos fundamentales de IA utilizando Python.

## Herramientas

- **Editor**: Spyder
- **Gestor de paquetes**: Anaconda Navigator
- **Lenguaje**: Python

## Contenido

Este repositorio contiene ejercicios prácticos sobre diversos temas de Inteligencia Artificial, incluyendo algoritmos de optimización como gradiente descendente, entre otros.

## Uso

1. Instalar Anaconda Navigator
2. Abrir Spyder desde el navegador de Anaconda
3. Ejecutar los scripts de los ejercicios
